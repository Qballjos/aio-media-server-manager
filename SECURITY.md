# Security policy

## Supported versions

Security fixes are provided for the latest stable release. Please update to the
latest release before checking whether a vulnerability is still present.
The `beta` branch is a development preview.

## Reporting a vulnerability

Please report suspected vulnerabilities privately through
[GitHub private vulnerability reporting](https://github.com/Qballjos/aio-media-server-manager/security/advisories/new).

Do not disclose vulnerabilities in public issues, pull requests, or discussions.
If private reporting is unavailable, wait until a private reporting channel is
available; do not post sensitive details publicly.

Include the affected version or commit, steps to reproduce, expected and actual
behavior, and the potential security impact. A minimal proof of concept is
helpful. Remove passwords, API keys, tokens, personal data, and private media
information from logs and screenshots.

Please allow maintainers time to investigate and coordinate a fix before public
disclosure. Response and remediation times depend on maintainer availability
and the severity of the issue.
